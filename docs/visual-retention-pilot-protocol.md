# Proposed visual-retention pilot: learning versus consolidation

Chromalect can test a narrow hypothesis about **when** a stable visual identity encoding is supplied. A machine-readable research protocol is at [postmastery-color-retention-protocol-v0.1.json](../data/research/postmastery-color-retention-protocol-v0.1.json). It is a planned design, not an outcome report or approval to enroll participants.

## Controlled arms

All arms teach the same source-grounded target component identities and use the same original character outlines. Plain control uses no component-identity colors at any stage. Early-color treatment uses the unchanged v0.6 identity palette before and after explicit mastery. Post-mastery treatment teaches in plain mode until a predetermined mastery criterion, then introduces the identical stable palette for subsequent practice. Consolidation exposure time, feedback and task difficulty must be matched. Assignment must be counterbalanced at the item level so that no participant sees the same target across different encoding arms.

## Observable endpoints

The primary endpoint is **unaided, color-free component-identity recognition** at pre-registered delayed test points (24 hours and seven days), comparing within-participant accuracy across matched item sets. Secondary exploratory endpoints include trials to mastery, latency, and transfer to new independently reviewed glyph compositions. Study protocol authors must fix the sample-size/power analysis, learning criterion, scoring and treatment order before collecting research results. Any deviation is separately dated and labeled.

## Required evidence gates

Source-aligned glyph generation alone is not independent visual certification. No item should enter the trial until the source path ownership is independently checked, the target identity labels are independently verified, and accessibility for the selected participants has been evaluated. Any semantic or lexical meaning arm requires its own external verification, currently outstanding. Legal/ethical review, consent, safe data retention, and analysis preregistration are also pending.

The published material collects **no participant responses**, records no individual-level data, does not run passive analytics and does not make a claim about educational effectiveness. All outcome counters remain zero. This scope isolates component identity from still-unadjudicated Chinese word meanings; later semantic hypotheses would be separate experiments.
