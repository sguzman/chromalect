# Offline Mandarin sentence candidate extraction

This optional tool converts an already downloaded Tatoeba Mandarin `cmn_sentences_detailed.tsv` source snapshot into **candidate sentence identifiers**, not verified pronunciations or word senses. It does not need browser automation, network access at runtime, or access to private projects.

Official source: [Tatoeba Mandarin detailed exports](https://downloads.tatoeba.org/exports/per_language/cmn/). Download the official `cmn_sentences_detailed.tsv.bz2` and run the [extractor](../tools/glyph-pipeline/tatoeba_context_candidate_extract.mjs) with explicit `--input`, `--snapshot-date`, and `--output` options; it accepts the compressed `.bz2` archive directly using the local `bzip2` executable, or an already decompressed TSV. The script refuses to overwrite an existing output path.

It reads the documented six-field detailed TSV format (ID, language, sentence, username, creation and modification dates). Some real export rows have unset creation or modification dates, which are represented as null rather than fabricated. Rows without contributor credit are counted and excluded from candidate output. Only `cmn` records are accepted. By default, up to three matching sentence IDs per first-tranche high-attention character are selected. Record ordering is based on the exact input snapshot; a SHA-256 hash of the uncompressed source makes the output reproducible. Candidate metadata includes Tatoeba ID, source URL, contributor and a sentence-text SHA-256 digest. **The exported JSON deliberately excludes complete sentence text.**

A matching surface character can occur in a different word, graph variant, or polyphonic context. Every emitted candidate is marked `readingInContext: not_checked`, `lexicalSense: not_checked`, and `corpusRecordLicense: requires_individual_check`. Actual Tatoeba sentence ownership and rights must be checked separately before quotation; the [corpus terms](https://en.wiki.tatoeba.org/articles/show/using-the-tatoeba-corpus) describe a CC BY 2.0 FR attribution requirement for textual material. The tool neither approves readings nor fills the contextual-evidence worksheet automatically.

The [synthetic smoke test](../tools/glyph-pipeline/tatoeba_context_candidate_extract_smoke.mjs) checks multiple-character matches, duplicate IDs, identical compressed/uncompressed source hashing, reproducible source references and omission of copyrighted sentence text. No synthetic fixture is committed as real corpus evidence, and no Tatoeba export is vendored into this repository.
