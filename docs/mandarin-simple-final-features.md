# Six Mandarin simple-final feature hypotheses

This is a tightly bounded source-catalog experiment, not a definitive Mandarin vowel inventory or an IPA transcription system. University pedagogical references describe the six *simple final spellings* `a, o, e, i, u, ü`. Chromalect records one provisional coarse **height / backness / lip-rounding** feature tuple for each spelling. These proposed tuples are unique in the six-item control but have **not** been independently adjudicated as Mandarin phonemes, surface phones or learnable symbols.

## Evidence and bounds

- [Hong Kong Polytechnic University — Simple Finals](https://www.polyu.edu.hk/bepth/introduction-to-phonetics/simple-finals/?sc_lang=en) describes the six pedagogical categories and cautions that `o` after labial initials may exhibit a transition resembling `uo`.
- [The Open University — Pronunciation guide, Finals](https://www.open.edu/openlearn/mod/oucontent/view.php?id=108700&section=1.1) treats post-sibilant written `i` differently from the default simple vowel and discusses the contextual `o` realizations.
- [LMU Munich — Mandarin vowel demonstration](https://www.phonetik.uni-muenchen.de/studium/skripten/languagedemos/Demos/mandarin.html) documents articulatory and transcription variation including apical-vowel/syllabic-consonant interpretations.

In the first pinned 1,171 citation readings, **432** have one of these six exact final strings; **112** fall into explicitly flagged contextual spelling categories (63 written `i` following sibilants, 33 palatal-context written `u`, and 16 labial-context written `o`). The remaining **320** are unflagged by this rule set, **not** independently verified phonetic realizations.

The [machine-readable ledger](../data/phonetics/mandarin-simple-final-feature-candidates-v0.1.json) preserves the original source label frequencies and earliest examples, references, caveats, and zero certification counters. It does not copy external audio or glosses, and it does not change the existing component, final-color or tone palettes.

Future genuine vowel-feature work must distinguish phonemic versus phonetic representations, contextual allophony, dialect and speaker variability, and verified transcription conventions. These six working tuples are only an experimental comparison baseline.
