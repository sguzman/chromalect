# Feature-level decoding of the Zhao–Li CVVVCT research model

The existing [EXP-0002 phonetic-symbol experiment](../experiments/EXP-0002-featural-pronunciation.md) requires decoding *articulatory structure*, not merely replacing Pinyin letters with other symbols. The new [feature grammar](../tools/glyph-pipeline/zhao_li_visual_feature_grammar.mjs) directly encodes the separate [34-unit Zhao–Li (2009) research phonology](../data/phonetics/zhao-li-2009-34-unit-reference-model-v0.1.json). This is a source-model control, not an accepted Standard Mandarin phonemic inventory.

**Grammar.** A declared input tuple consists of optional consonant onset C, 1–3 ordered source vowel units V–V–V, optional nasal coda C, and independent citation tone T. Consonants are encoded by source place, manner, and voicing/aspiration features. Vowels use source place/backness, height, and rounding. Tone uses its separate source category symbol. The encoded visual-feature tokens store **no original model-unit spelling**, IPA word, or Pinyin final string. Reconstruction consults the published source-model feature registry, refusing unsupported combinations, ambiguous tuples, unknown fields, invalid CVVV occupancy, impossible model codas, and missing tone categories.

**Evidence.** The [machine-readable audit](../data/phonetics/zhao-li-visual-feature-grammar-audit-v0.1.json) contains 34/34 individually reconstructed units plus nine structured source-model demonstrations. The [grammar adversarial tests](../tools/glyph-pipeline/zhao_li_visual_feature_grammar_smoke.mjs) cover deliberate collisions and invalid tokens, while the [interactive six-slot inspector](../site/mandarin-model-feature-grammar.html) visualizes independent segment-feature shapes with a separate viewer acceptance test.

**Scientific limits.** Machine reversal of typed feature records does not show that a human can read the SVG shapes, nor that every formally expressible unit sequence is an attested Mandarin syllable. The proposed 34-unit model is not independently adjudicated as Chromalect's phonemic reference, and the source's nonstandard apical vowels and retroflex `r` remain analysis-dependent. This feature does not map an accepted actual phoneme sequence to any of the first 1,171 source Pinyin citations. Acoustic realization, human decoding, learning transfer, shape legibility, contextual sandhi, and phonemic inventory certification all remain at **zero**. The active component palette and original Chinese glyph strokes are unchanged.

The Phase 2 decoding grammar and genuine-sound acceptance criteria remain **unchecked** until phonemic input records, independent visual comprehension, and source-specific phonological adjudication are available.
