## Reading a record

Character **清** has an IDS such as `⿰氵青`. At the active macro component cut this means 氵 plus 青, each mapped to its v0.4 identity color. This is **composition metadata**; accurate whole-glyph coloring needs actual stroke ownership or masks not yet available.
