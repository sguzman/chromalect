Contour-only decoding practice (non-study)

Eight balanced, locally shuffled prompts show only the original monochrome relative-pitch shape, with no glyph, Pinyin, initial, final, color or contour name in the prompt. Choose T1–T4 to see immediate source-label feedback. Neutral tone is excluded because no independent contour is defined.

This session is not a controlled human study: no consent, sampling, preregistration, calibrated acoustics, data export or retention measurement is provided. Answers exist only in the current browser session.

Blind tone-shape recognition (local-only research instrument)

This is a separate 16-trial recognition assessment, not the feedback-based practice above. Each of the four idealized citation contours appears exactly four times in randomized blocks of four. Prompts contain no character, Pinyin, initial, final, sound, color or semantic cue. Answer ordering is randomized independently. The correct tone is not revealed between trials; only after all 16 responses is a score and locally copyable JSON record produced.

Optional self-assessment only. It does not collect a name, health details, age, identifiers, device fingerprint, response time or IP through an experiment submission. Responses are kept in the current page session; the project does not upload or save them. There is no validated recruitment, participant verification, independent ethics review or control group. This does not yet count as an independently controlled human result. Neutral tone remains excluded because no independent context-free shape is defined.

Validating source-only assessment.
