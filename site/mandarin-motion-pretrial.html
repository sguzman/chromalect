Phase 3 · reduced-motion comparison stimuli · preparation only

Static and single-play animated information cues

Compare unchanged information in a static reference against an optional, one-shot sequential reveal. Semantic event cues come from the 1,000-character draft Unihan screening; articulatory place, manner and aspiration categories come from the provisional 21-initial Mandarin source codebook. No glyph ownership, identity colors, transcriptions or meaning claims are changed by the animation.

No study or evidence of learning gain. This is a prospective comparison stimulus, not an authorized participant trial. It collects no responses, stores no session state, and does not upload observations. Motion is never automatic; it is disabled when the operating system requests reduced motion. Animations do not depict measured tongue, lip, airflow, or acoustic trajectories.

Validating research candidate sources.

Control: static

All source tokens visible at once; no transitions.

Candidate: sequential reveal

Same source tokens and ordering. One short motion sequence only when manually activated.

Opt-in static versus one-shot motion recall instrument

Sixteen randomized exposures compare identical source-derived information in static and manually activated, single-play sequential-reveal conditions. Four distinct draft semantic-event pictograms and four provisional articulatory feature cues each appear once per condition. After viewing a cue, hide it and identify its proposed meaning or the initial's proposed articulatory place from four alternatives. Feedback is withheld until the entire session finishes.

This is not a validated user study. Source meanings and articulation classifications are provisional. Exposure duration is self-paced, randomized assignment does not control participant knowledge, and answers are only unverified current-session observations. No demographics, device fingerprints, identities, timings, or automatic network uploads/storage are collected. A system reduced-motion preference always overrides the one-shot condition, which is recorded as a static exposure. One-shot animations never autoplay.
