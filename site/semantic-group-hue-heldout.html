Color research · source-ranked held-out character evaluation

Do experimental hue groups transfer to unseen characters?

The previous collision-reduced v0.2 experiment used all 1,000 known Chinese glyphs both to optimize and measure component-color proximity. This stricter numerical experiment generates five independently fitted color candidates, each using only 800 original source glyphs; the other 200 are reserved for evaluation. Every Chinese character is held out exactly once.

Research-only controls. Colors are selected using the original historical mnemonic hints, which are not independently accepted linguistic semantic families. These measurements assess OKLab distances between component color pairs inside source glyphs, not human perception, retention, reading or accessibility compliance. The active v0.6 colors are not changed.
