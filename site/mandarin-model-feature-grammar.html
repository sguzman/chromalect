Decode phonological features, not Pinyin letters

Construct an ordered CVVVCT sequence using the 34 phonological units in the Zhao–Li research model: 21 possible onsets, 12 vowel units, two nasal coda choices and an independent citation-tone category. Each segment renders from articulatory feature tuples without retaining the source model's unit letters inside its encoded visual shape.

The six-slot grammar here is **formal source-model syntax**, not a test of which syllables are actually permitted or produced in Mandarin. The input and reconstructed token strings are visible for technical inspection; this is not a blinded participant study. The published model is not adopted as Chromalect's frozen phonological inventory.

Feature-constructed visual code

Consonants use outer place geometry, inner manner marks and voicing/aspiration decorations. Vowels use a relative height/backness grid and a rounding marker; special apical categories retain separate model features. The tone symbol has an independent fixed slot.
