# Decision records

Decisions capture the **reason for choices**, not just their current value.

Use stable identifiers: DEC-0001, DEC-0002, and so on. Each record has status (accepted / provisional / rejected / superseded), date, context, decision, consequences, and how to revisit. Do not silently rewrite an accepted decision; record revisions or supersession.
